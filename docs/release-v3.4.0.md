# Motion Lab V3.4.0

- 独立动效工作台：八种动效、时间轴关键帧、A/B、预设资产和回收站。
- 多轨道编排：分组、延迟、吸附、手势录放、内置实测 FLIP / 共享元素轨道、组合预览。
- 单动效和编排工程 HTML、Vue、React、ZIP 导出；统一运行时及清理。
- 物理弹簧、平移与缩放速度继承、连续中断验证。
- 可折叠/调整面板、移动端默认聚焦、跨浏览器视觉与性能回归。

部署入口：https://weepwood.github.io/Motion-Lab/?workspace=1

发布资产为通过主分支 CI 的静态 Web 产物 ZIP，解压后使用 HTTP 静态服务器运行；不依赖桌面安装包。SHA256SUMS.txt 用于完整性核验。

边界：内置布局场景并非任意外部 DOM 编排；CI 帧间隔与 Chromium 堆采样不等同于真实设备 GPU 测量或无泄漏证明。
